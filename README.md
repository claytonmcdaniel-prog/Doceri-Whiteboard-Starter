# Doceri-Whiteboard-Starter

SwiftUI + PencilKit iPad whiteboard starter — the foundation for a Doceri replacement built by Clayton.

## Quick Start

```bash
git clone https://github.com/claytonmcdaniel-prog/Doceri-Whiteboard-Starter.git
cd Doceri-Whiteboard-Starter
open DoceriWhiteboard/DoceriWhiteboard.xcodeproj
```

Full documentation, sprint backlog, and source files pushed via CLI — see project root for README.md.

## Features
- PencilKit canvas (ink, eraser, lasso, ruler)
- Multi-page whiteboard with page navigation
- Undo / redo
- PNG export
- PDF import (renders each page as background layer)
- Autosave to Documents directory

## Stack
- SwiftUI + PencilKit + PDFKit
- Zero third-party dependencies
- GitHub Actions CI (macOS runner)

*Built with SwiftUI + PencilKit. Goal: replace Doceri with an open, extensible whiteboard.*
